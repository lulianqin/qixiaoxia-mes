# 纸袋产品全流程端到端（E2E）测试执行步骤

> 适用范围：纸袋工厂新版本上线验收、新客户/新产品试跑、回归测试。
> 目标：用**一张销售订单**穿过「主数据 → 销售 → 采购 → 工艺路线 → 工单 → 排产 → 领料/发料/退料 → 分切 → 印刷 → 外协加工 → 制袋 → 检验 → 包装 → 完工入库 → 销售出库 → 发运 → 客户签收」全过程，并验证**每个环节的库存增减、状态流转、质检门禁**都正确。
> 依据：`frontend/public/help/` 用户帮助文档 + 本项目实际接口与状态机。
> 最近更新 2026-11-02：新增「外协内部代办模式」（6.0）、分切子卷实际门幅/克重写入与历史回填（6.1、D.6）。

## 〇、测试概况

### 0.1 测试链路

```
主数据(单位/分类/物料/BOM/供应商价格/工艺路线/工作站/检验模板)
   └─▶ 销售订单(待确认→已确认) ──▶ 生成工单 ──▶ 排产
                                   │
   原材料采购下单→到货登记→IQC→确认收货→过账→批次标签
                                   │
                              开工四步检查(齐套/排产/领料/开工)
                                   │
        领料单(草稿→待审→已下达→已预占→已发料) ──▶ 退料单(RQC→执行退库)
                                   │
   分切(外协) → 印刷(厂内) → 外协加工 → 制袋(厂内) → 检验 → 包装(厂内)
                                   │
              末序报工审核 → 自动生成产品入库单 → IPQC → 入库过账
                                   │
        销售出库(从销售订单) → OQC → 出库确认(扣库存) → 发运(在途) → 客户签收
                                   │
                     库存现有量 / 库存事务 / 批次追溯核对
```

| 4.7 | 若排产未通过：点「去甘特指派机台/负责人」补齐；急单可「豁免开工」并填理由 | 豁免理由记入工单变更 |

**校验断言**
- 工单状态：PREPARE → PRODUCING。
- 流转卡列表新增 1 张卡，数量=计划量，状态=流转中；可点「二维码」打印。
- 领料单生成：草稿状态，明细与 BOM 对应。

## 七、阶段 5：领料 → 预占 → 发料；完工后退料

> 对应《生产领料与生产退料》。

### 7.1 领料与发料

| # | 操作 | 预期结果 |
|---|------|---------|
| 5.1 | 仓库管理 → 生产领料（或用开工自动生成的单）→ 核对明细、选发料仓库、流转卡 | 申请数量可按本单调整 |
| 5.2 | 「提交审核」 | 草稿 DRAFT → 待审核 PENDING |
| 5.3 | 「审核通过」 | 已下达 APPROVED |
| 5.4 | 「预占库存」 | 已预占 ALLOCATED；**可用量下降，现有量不变** |
| 5.5 | 「发料出库」→ 添加发料明细（本次发 1/2）→ 确认发料 | 状态=部分发料 PARTIAL_ISSUED；现有量减少 |
| 5.6 | 再次「发料出库」发剩余 1/2 | 状态=已发料 ISSUED |
| 5.7 | 手机端「扫码发料」扫批次码（可选回归） | 自动匹配领料行与批次 |
| 5.8 | 全部发完点「关闭」 | 已关闭 CLOSED |

> 未开工直接发料会被拦截，必须先做 4.6 开工。

### 7.2 退料（余料退回）

| # | 操作 | 预期结果 |
|---|------|---------|
| 5.9 | 仓库管理 → 生产退料 → 「从领料单生成」→ 选已发料单据（显示可退量=已发料−已报工消耗） | 生成退料草稿，仅剩余物料成行 |
| 5.10 | 调整退料数量、批次号 → 保存 | 草稿 DRAFT；若物料绑定了 RQC 模板，自动生成退料检验单 |
| 5.11 | 质量 → 退料检验（RQC）→ 判定合格/让步接收 | 退料单检验状态=检验合格 |
| 5.12 | 退料单「执行退库」→ 确认 | 状态=已退库 POSTED；**库存增加**，生成库存事务 |

**校验断言**
- 领料明细：申请量 = 已发量 + 未发量。
- 退料量 ≤ 已发料量 − 工单已消耗量。
- 库存事务：领料出库为负、退料为正，逐条可查。

## 八、阶段 6：逐工序执行（分切 → 印刷 → 外协 → 制袋 → 检验 → 包装）

> 对应《外协管理》《生产报工》《质量检验》。**串行路线必须按顺序报工；外协工序厂内不能报工。**

### 6.0 外协操作的两种模式（先确认用哪种）

| 模式 | 操作人 | 入口 | 需要权限 | 审计 |
|------|--------|------|---------|------|
| A 厂商自助 | 外协厂商账号 | 手机 H5 → 工作台「外协任务」→ 我的外协任务 | 厂商角色（`vendor`） | 写 `vendor_receiver / finish_by / ship_by` |
| B 内部代办 | 工单负责人 / 工序负责人 | PC「仓库管理 → 外协管理」或手机「外协单」 | `mes:wm:outsource:agentOps` | 额外写 `agent_operator`（代操作人） |

**按状态出现的按钮（PC 与手机一致）**

| 外协单状态 | 可操作 | 动作按钮 |
|-----------|--------|---------|
| 草稿 DRAFT | 本厂仓管 | 执行发料 / 删除 |
| 已发料 ISSUED | 厂商或代操作人 | 签收 |
| 厂商已签收 VENDOR_RCVD | 厂商或代操作人 | 录入结果 |
| 加工中 PROCESSING | 厂商或代操作人 | 补录 / 完成 |
| 已完成 FINISHED | 厂商或代操作人 | 发货回厂 |
| 已发货 SHIPPED | 本厂仓管 | 去检验（有 IQC 时）/ 收货 |
| 已收货 RECEIVED | — | 查看检验结果 |

> **代操作权限授予**：系统管理 → 角色管理 → 勾选「代厂商操作」。默认已授予 `仓库管理`、`生产管理`，`admin` 自动拥有。
> **判断是否代录**：外协管理列表「代操作人」列有值 = 内部员工代办；为空 = 厂商本人操作。

### 6.1 分切（外协，厂商=万隆）

| # | 角色 | 操作 | 预期结果 |
|---|------|------|---------|
| 6.1.1 | 本厂仓管 | 工单开工后，系统按外协工序生成**草稿外协单**（来源=分切），预填发料明细与仓库/批次 | 外协单状态=草稿 DRAFT |
| 6.1.2 | 本厂仓管 | 核对发料行 → 「执行发料」 | 状态=已发料 ISSUED；**原料库存扣减**；流转卡=外协中 |
| 6.1.3 | 外协厂商 **或** 代操作人 | 手机端「我的外协任务」/ PC 外协管理 → 「签收」 | 状态=厂商已签收；代操作时「代操作人」列显示当前账号 |
| 6.1.4 | 外协厂商 **或** 代操作人 | 「录入结果」：添加产出明细，逐条填**数量/门幅/克重**（同规格可批量添加，≤50 条）→ 提交 | 状态=加工中；累计录入 ≤ 发料量；**子卷写入实际门幅/克重** |
| 6.1.5 | 外协厂商 **或** 代操作人 | 补录至录满（或短交点「手动完成」）→「发货回厂」 | 状态=已完成 → 已发货；系统自动生成**来料检验单** |
| 6.1.6 | 质检员 | 来料检验（IQC）→ 判定合格/让步接收 | 检验状态=检验合格；未判定时收货被拦截 |
| 6.1.7 | 本厂仓管 | 外协管理 → 「收货」 | 状态=已收货；**分切后半成品新批次入库**；自动生成外协报工；**流转卡推进到印刷** |

**校验断言**
- 库存：发出母卷批次减少；分切产出（纸卷）新批次增加。
- 纸卷明细：新子卷的 **实际门幅 / 实际克重** 与 6.1.4 录入值一致（不能为空）；可按纸卷码 `QXX|ROLL|...` 查规格/母卷、打印标签。
- 追溯：子卷 → 母卷（`parent_roll_id`，建单带 `sourceRefId` 时）→ 外协单 → 收货报工 → 库存批次，链路可查。
- 状态与审计：状态按 `草稿→已发料→已签收→加工中→已完成→已发货→已收货` 推进；代操作时 `agent_operator` 有值。
- 防重：同一工单同一工序再建外协单应被拒绝。

> **发货回厂物流信息（当前不实现，列为后续可完善项）**
>
> 现状：「发货回厂」只记录状态、发货时间、操作人（`ship_time / ship_by / agent_operator`），**不采集物流信息**。
> 决策：本次不加，避免拖慢现场操作（同城短途/厂商自送时无实际价值）。
> 后续可完善方案（选填、不设必填、折叠展示）：发货方式（自送/物流/快递）、承运商、运单号、车牌/司机、发货件数/箱数、预计到货、回单照片。
> 建议与「收货差异登记」一起做：收货时登记实收数量与差异，比发货物流信息更能覆盖短交/丢件场景。
> 适用：分切与外协加工两种外协工序通用。

### 6.2 印刷（厂内）

| # | 角色 | 操作 | 预期结果 |
|---|------|------|---------|
| 6.2.1 | 班组长 | 排产任务「下发」给 1 号印刷机（负责人已指定） | 任务=生产中 |
| 6.2.2 | 操作工 | 手机端扫流转卡 → 报工页：合格数 1000、不合格数 0、工废/料废按需；物料消耗自动带出油墨 | 提交后报工=待确认 PREPARE |
| 6.2.3 | 操作工 | 填工序参数（色差等），超范围行标红"偏差" | 参数保存 |
| 6.2.4 | 班组长 | 生产报工列表「确认」→「审核」 | 报工=AUDITED；流转卡推进到外协加工 |
| 6.2.5 | 校验 | 物料消耗页签按 BOM 扣油墨；报工列表「检验状态」列显示过程检结果 | 与 6.4 检验联动 |

### 6.3 外协加工（外协，厂商=万隆）

重复 6.1 的 7 个动作（本厂执行发料 → 签收/录结果/完成/发货 → IQC → 本厂收货），**签收/录结果/完成/发货**可选「厂商自助」或「内部代操作」两种模式（见 6.0）。
**预期**：外协单状态全链路走完；流转卡推进到制袋；外协工序厂内扫码报工应提示"下一道为外协工序"；收货后物料按**发料物料**入库（通用外协不换料，见表后说明）。

> **库存口径提醒（2026-11-02 核实）**
> - **分切**：收货入的是**同一原料物料**的新批次 + 纸卷明细（门幅/克重），不是独立半成品物料；按规格统计库存要查「纸卷明细」。
> - **通用外协加工**：收货物料必须在发料明细中（后端硬校验），**不支持"投入 A 产出 B"的独立半成品库存**。若业务需要半成品独立库存，应拆成独立半成品工单走产品入库，或等系统补"工序产出物料"模型。

### 6.4 检验（厂内，工序需检）

| # | 角色 | 操作 | 预期结果 |
|---|------|------|---------|
| 6.4.1 | 质检员 | 质量 → 过程检验单（IPQC）→ 打开工单/报工生成的过程检单（或手工建单） | 检验单存在 |
| 6.4.2 | 质检员 | 录入实测值 → 保存 → 执行判定 | 合格则后续入库不被拦截；不合格则任务显示「不可开工」 |
| 6.4.3 | 班组长 | 若「不可开工」，需「质检放行」填理由 | 解除锁定并留痕 |

### 6.5 制袋（厂内）

| # | 操作 | 预期结果 |
|---|------|---------|
| 6.5.1 | 排产任务下发到 1 号制袋机 | 任务=生产中 |
| 6.5.2 | 扫流转卡报工：合格数 1000、不合格数 0；物料消耗带出胶水 | 报工待确认 |
| 6.5.3 | 班组长确认 + 审核 | 流转卡推进到检验 |
| 6.5.4 | 校验：报工「上机数量」预填正确；修改会留痕 | 修改痕迹抽屉可查 |

### 6.6 包装（厂内，末工序）

| # | 操作 | 预期结果 |
|---|------|---------|
| 6.6.1 | 排产任务下发到包装工作站 | 任务=生产中 |
| 6.6.2 | 报工：合格数 1000、不合格数 0（按箱数填「待检测」等） | 报工待确认 |
| 6.6.3 | 班组长「确认」→ 末工序「审核」 | **自动触发**：累加工单已生产数、生成**产品入库单**、生成**退料单**、流转卡=已完工；产量达计划 → 工单**自动完工** |

**校验断言**
- 工单状态=COMPLETED。
- 产品入库单自动生成（仓库管理 → 产品入库，状态 DRAFT）。
- 流转卡=已完工。
- 退料单草稿按剩余物料生成。

## 九、阶段 7：完工入库（含 IPQC）→ 打印成品批次标签

| # | 操作 | 预期结果 |
|---|------|---------|
| 7.1 | 仓库管理 → 产品入库 → 打开自动生成的入库单 | 明细=成品、数量=合格数、仓库=成品仓 |

## 十、阶段 8：销售出库（含 OQC）→ 发运 → 客户签收

> 对应《订单到交付主流程》第 6~7 步。

### 8.1 销售出库

| # | 操作 | 预期结果 |
|---|------|---------|
| 8.1.1 | 仓库管理 → 销售出库 → 「从销售订单」→ 选阶段 2 的订单 | 自动带出客户、产品、待发数量 |
| 8.1.2 | 核对明细、出货仓库=成品仓 → 保存 | 单据=草稿 DRAFT |
| 8.1.3 | 若产品绑定 OQC：质量 → 出货检验单 → 判定合格/让步接收 | 出库单检验状态=检验合格 |
| 8.1.4 | 「出库确认」→ 弹窗扫成品批次码（可扫多个批次）→ 确认 | 状态=已出库 POSTED；**成品库存扣减**；批次精确扣减 |
| 8.1.5 | 不扫批次直接确认（回归 FIFO） | 按先进先出自动分配批次 |

| # | 操作 | 预期结果 |

**校验断言**

- 签收后订单交付完成；发运回单与物流信息留档。

## 十一、阶段 9：库存与追溯终检（必做）

| # | 校验项 | 入口 | 预期 |
|---|--------|------|------|
| 9.1 | 原料账面守恒 | 仓库管理 → 库存现有量 | 期初 + 采购入库 − 领料发料 + 退料 = 结存 |
| 9.2 | 成品账面守恒 | 同上（成品仓） | 0 + 完工入库 − 销售出库 = 结存 |
| 9.3 | 每笔变动有流水 | 仓库管理 → 库存事务 | 采购入库/领料出库/退料入库/产品入库/销售出库 均有记录 |
| 9.4 | 批次可追溯 | 生产 → 物料追溯 | 销售批次 → 入库单 → 工单 → 报工 → 领料 → 采购批次 全链路可查 |
| 9.5 | 检验闭环 | 质量管理四类检验单 | IQC/IPQC/OQC/RQC 均有判定记录且与业务单据状态一致 |
| 9.6 | 单据状态机 | 销售订单/工单/领料/外协/入库/出库/发运 | 状态按顺序推进，无跳级、无回退 |
| 9.7 | 异常无残留 | 工单列表「异常N」角标 | 无未关闭异常（如有需处理关闭） |

**通过标准**：以上 7 项全部满足，且 9.1/9.2 数量精确相等（允许 0.0001 以内的四舍五入差异）。

## 十二、阶段 10：逆向/异常用例（建议同批执行）

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| 10.1 | 缺料异常 | 报工页「报异常」→ 缺料 → 主管在异常台账「开补料采购」 | 自动生成草稿采购单，与异常单关联 |

## 十三、验收判定清单（逐项打勾）

- [ ] 主数据：单位/分类/物料/BOM/客户/供应商价格/车间/工作站/工序/路线/检验模板 全部可用
- [ ] 销售订单：待确认 → 已确认 → 转工单，部分转单正确
- [ ] 采购：草稿 → 审批 → 下单 → 到货登记（不动库存）→ IQC → 确认收货（加库存）→ 过账
- [ ] 工单：齐套检查 → 排产（机台+负责人）→ 开工四步 → 自动领料单 + 流转卡
- [ ] 领料：草稿 → 待审 → 已下达 → 已预占 → 部分发料 → 已发料 → 关闭
- [ ] 外协（分切/外协加工）：草稿 → 发料 → 签收 → 录结果 → 完成 → 发货 → IQC → 收货，流转卡推进（签收/录结果/完成/发货支持厂商本人或内部代办，代操作人可见）
- [ ] 分切规格：收货后纸卷明细的「实际门幅/实际克重」非空且与录入一致
- [ ] 厂内工序：报工 → 确认 → 审核，参数偏差提示、上机数量留痕
- [ ] 检验：IPQC 拦截入库、OQC 拦截出库、IQC 拦截过账、RQC 拦截退库
- [ ] 完工：末序审核自动生成产品入库 + 退料单 + 工单完工
- [ ] 入库：确认 → 打印批次标签 → 过账，成品库存增加
- [ ] 出库：从订单生成 → 扫码精确扣批 → 出库确认，成品库存减少
- [ ] 发运：在途 → 客户签收，订单变已发货
- [ ] 库存：原料与成品数量守恒，库存事务完整，批次可追溯
- [ ] 逆向：采购退货、销售退货、盘点差异按单据走，不改账面数

## 附录 B：常见卡点对照表

| 现象 | 根因 | 处理 |
|------|------|------|
| 工单点「开工」被拦：物料不齐 | 库存不足/未采购入库 | 齐套看板 → 生成采购单或领料单补料 |
| 开工被拦：未派机台/未指定负责人 | 排产未落实到人 | 点弹窗「去甘特指派」补齐后重试 |
| 发料提示"工单尚未开工" | 未执行开工 | 先做阶段 4.6 开工，再发料 |
| 预占失败：可用量不足 | 未审核/未预占或库存被占用 | 先审核再预占；检查库存现有量 |
| 外协单选不到厂商 | 供应商类型不是"外协加工商" | 供应商档案改为外协类型 |
| 外协单停在「已发料」，没人签收/录结果 | 厂商不登录系统 | 用内部代办：需 `mes:wm:outsource:agentOps` 权限，PC/手机点「签收→录结果→完成→发货回厂」 |
| 外协管理看不到「签收/录结果/完成/发货回厂」按钮 | 内部账号没有「代厂商操作」权限 | 系统管理 → 角色管理，勾选「代厂商操作」后重新登录 |
| 外协收货被拦 | 厂商未「发货回厂」或 IQC 未合格 | 代办人先点「发货回厂」；再做 IQC 判定 |
| 扫码提示"下一道为外协工序" | 正常提示：该工序已外发 | 由厂商端/代办人录结果，本厂收货后自动推进 |
| 分切纸卷明细门幅/克重为空 | 旧版本未写入（V168 已回填历史） | 确认外协单为分切来源且录入时填了门幅/克重；新单据自动写入 |
| 入库/出库被拦：需检验 | IPQC/OQC 未判定 | 到对应检验单判定合格或让步接收 |
| 出库提示"批次不存在/仓库不符" | 批次不在出货仓库或编码错 | 核对批次标签与出货仓库 |
| 工单不能完工 | 有未关闭异常单或产量未达标 | 处理并关闭异常；继续报工 |
| 订单转工单按钮不出现 | 订单状态不是已确认 | 先点「确认/接单」 |
| 检验单不生成 | 物料未绑定检验模板 | 检验模板「适用物料」绑定该物料 |

### D.7 外协库存口径结论（测试判定基线）

| 场景 | 收货物料 | 是否独立半成品库存 | 规格怎么查 |
|------|---------|------------------|-----------|
| 分切 | 与发料母卷**同一物料** | 否，按新批次入原料库存 | 纸卷明细的 `实际门幅/实际克重` |
| 通用外协加工 | 必须是发料明细中的物料 | 否，不支持投入 A 产出 B | 按发料物料+批次 |

> 若验收要求"半成品作为独立物料单独统计库存"，当前版本不满足，需要另立需求（工序产出物料模型或拆独立半成品工单）。
